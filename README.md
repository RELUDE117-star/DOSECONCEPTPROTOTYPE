# DOSE Home Station

## Setup

1. Download ZIP (green **Code** button → **Download ZIP**)
2. Unzip the folder
3. Double-click **DOSE_INSTALL.sh** → pick **"Execute in Terminal"**
4. Type your Raspberry Pi password when asked
5. The app launches automatically — a DOSE shortcut is now on your desktop

## No camera yet?

The app works without the camera. It shows "Camera not connected" on screen.
Tap the screen to walk through the demo flow manually.

## Controls

| Key | Action |
|-----|--------|
| **Esc** | Quit |
| **Tap** | Advance through dispense flow |
| **c** | Toggle camera preview |
