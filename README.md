# DOSE Home Station

## Setup

1. Download ZIP from this page (green **Code** button → **Download ZIP**)
2. Unzip it
3. Double-click **`DOSE_INSTALL.sh`**
4. Pick **"Execute in Terminal"**
5. Enter your Raspberry Pi password when asked
6. Done — the app launches automatically

## Controls

| Key | Action |
|-----|--------|
| **Esc** | Quit the app |
| **c** | Toggle camera preview |
| **Tap screen** | Advance through dispense flow |

## Hardware

- Raspberry Pi 4B
- Raspberry Pi Camera Module 3 Wide (120° FOV)
- Elecrow 5" 800×480 capacitive touchscreen
